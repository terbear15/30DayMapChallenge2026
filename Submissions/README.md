# MUSA gallery entries

Copy the three files from _maps_2026/ to the matching folder in your fork of weitzman-musa/30DayMapChallenge. Copy assets/thumbnails/2026/ to the matching thumbnail folder. The entries already link to the daily scripts in this repository.

Only these descriptions and thumbnails belong in the shared gallery repository. The complete code, source data, and exported maps remain here. Open a pull request after following the class demonstration.
